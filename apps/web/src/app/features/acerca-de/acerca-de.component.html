Acerca de

Un IDE colaborativo, construido como proyecto de portfolio

CodeSync es una plataforma educativa para aprender a programar en equipo: editor sincronizado en tiempo real, desafíos con ejecución sandboxed y un Coach de IA que da feedback cuando algo falla.

Por qué existe

Nace como proyecto de portfolio de Mateo Pavoni: una excusa para construir, de punta a punta, un producto real — desde la arquitectura del backend hasta el sandbox de ejecución de código y la colaboración en tiempo real — no un tutorial ni un CRUD de juguete.

Cómo está construido

Monorepo con backend en .NET 8 (Clean Architecture + CQRS) y frontend en Angular 20 standalone. Firebase resuelve autenticación, sincronización en tiempo real (editor, cursores, chat) y persistencia de desafíos y progreso. El código se ejecuta en contenedores Docker aislados, y el Coach de IA usa la API de Gemini.

  • .NET 8 · Clean Architecture
  • Angular 20 standalone
  • Firebase (Auth, Firestore, Realtime DB)
  • Docker sandbox
  • Gemini API

Qué sigue en el roadmap

Este es un MVP enfocado. Fuera de alcance por ahora, pero planeado:

  • Más lenguajes (Java, Go, Rust)
  • Leaderboard y badges
  • Modo profesor
  • Rate limiting distribuido (Redis)
