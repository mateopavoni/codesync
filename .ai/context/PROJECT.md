# Proyecto

- **FACT** IDE colaborativo para aprender a programar: editor Monaco sincronizado, 34 desafíos sembrados en 7 lenguajes, ejecución sandboxed en Docker, IA Coach y salas de hasta 4 personas.
- **FACT** Stack: .NET 8 (Clean Architecture + CQRS/MediatR), Angular 20 standalone, Firestore + Realtime DB + Auth (Firebase), Docker para el sandbox, OpenRouter para el IA Coach.
- **FACT** Estado: **archivado** (2026-10-08). El deploy en Dokku y el proyecto Firebase original se dieron de baja; corre 100% local con los emuladores de Firebase (`docker compose up --build`).
